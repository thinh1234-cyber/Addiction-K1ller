Chrome Extension giúp ẩn triệt để News Feed gây xao nhãng.



---

## ⚡ Tính Năng Nổi Bật

- **Loại Bỏ Feed Chuẩn Xác:** Chỉ ẩn luồng bài viết ở giữa không làm vỡ UI.
- **Custom Site & Subdomain Hard Blocker (Chặn Hẳn 100% Tùy Chỉnh):** Dừng truy cập hoàn toàn đối với các tên miền tùy chỉnh do người dùng thêm vào.
- **Bảo Vệ Tính Năng Nhắn Tin:** Giữ nguyên khung DMs, khung tìm kiếm YouTube & menu điều hướng.
- **Thay Thế Bằng Banner Tập Trung:** Chèn banner nhắc nhở tại vị trí Feed bị ẩn.
- **DOM Element Zapper:** Cho phép click chọn để ẩn bất kỳ phần tử gây xao nhãng khác.
- **Khôi Phục Nhanh:** Nút khôi phục lại các phần tử đã ẩn thủ công.
- **Giao Diện Pastel VS Code:** Hỗ trợ 5 chủ đề màu.
- **Nút Update Tự Động:** Kiểm tra phiên bản mới.

## 🚀 Hướng Dẫn Cài Đặt

1. Clone hoặc tải repository này về máy:
   ```bash
   git clone https://github.com/thinh1234-cyber/Addiction-K1ller.git
   ```
2. Mở trình duyệt Google Chrome hoặc Brave/Edge và truy cập: `chrome://extensions/`
3. Bật **Chế độ dành cho nhà phát triển (Developer mode)** ở góc trên bên phải.
4. Nhấp chọn **Tải tiện ích đã giải nén (Load unpacked)** và chọn thư mục chứa dự án `kill addiction`.
5. Ghim biểu tượng **Kill Addiction 🛡️** lên thanh tiện ích để sẵn sàng sử dụng!
